# QIDI-Tech X-Plus 3 Professional Config

## Purpose

This repository archives the stock Klipper configuration for the QIDI X-Plus 3 3D printer. It serves as a reference baseline for the printer's standard settings and configuration files.

## Contents

- **printer.cfg** - Main Klipper printer configuration
- **fluidd.cfg** - Fluidd web interface configuration
- **Adaptive_Mesh.cfg** - Adaptive mesh bed leveling configuration
- **MKS_THR.cfg** - MKS THR board configuration

## Branch Information

This is the `stock` branch, containing the original manufacturer configurations as shipped with the QIDI X-Plus 3 model.
